# Capturas de Pantalla para el Proyecto GPS

Coloca aquí las capturas de pantalla de la aplicación para el entregable:

6. `06_archivo_txt_ruta.png`: Captura del archivo `ruta_gps.txt` descargado y abierto en un editor de texto.
